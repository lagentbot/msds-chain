# MSDS Chain

This repository is a pointer. It contains no server code.

The MSDS Chain MCP server is developed at
[github.com/littleblakew/msds-chain-mcp](https://github.com/littleblakew/msds-chain-mcp).
Setup instructions for each client, the tool list and the license are in that repository's README.

## Connect

MSDS Chain is a hosted MCP server, so there is nothing to build or run locally:

```
https://mcp.lagentbot.com/mcp
```

For Claude Code:

```bash
claude mcp add msds-chain --transport http https://mcp.lagentbot.com/mcp
```
